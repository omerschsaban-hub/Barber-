# Sharpened 20× architecture

Fabrient's existing 20 app/MCP capabilities remain the surface. Underneath them is now a shared evidence contract spanning:

**geometry/CV → deterministic checks → DFM/fix/revalidation → physics → uncertainty → physical test → measurement/CV → residuals → ML/system identification → calibration → active learning → cross-modal disagreement → evidence-backed release.**

The design explicitly avoids product sprawl. The LLM is an evidence-aware orchestrator, not an engineering authority.
